## One-command workflow

```bash
bash material_review/run_end_to_end_docker.sh DATA_DIR WEIGHTS_DIR OUTPUT_DIR
```

The script runs the companion first and the main image second. It exits
non-zero unless the final scored-artifact hash and structural invariants pass.
The legacy tag `prelim-7.95236` is retained only for the earlier fast
artifact-reconstruction workflow; reviewers should use the two `e2e-*` tags.
