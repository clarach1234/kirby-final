## 2. Experiment Configuration

### 2.1 Datasets

We used the official GAVE2 training set for local model development. It
contains 50 cases (`g_001`–`g_050`), each comprising a 1536 × 1024 colour
fundus photograph (CFP), retinal region-of-interest (ROI) mask, RGB
artery/vessel/vein annotation, and registered early- and late-phase FFA
images. Task 3 additionally used the supplied training biomarker text files.
The preliminary cases (`g_051`–`g_100`) were used only for unlabeled
inference and public leaderboard evaluation; their ground-truth labels were
never accessed.

For Task 1, we additionally used the publicly released R2-V2 arteriovenous
specialist from the 2025 GAVE challenge. We fixed its repository commit to
`7f6a8ea7a51782b1e0f89723a9ec137ba0a29913` and verified the released AV
checkpoint by SHA-256. It was not fine-tuned on GAVE2 preliminary data.

### 2.2 Dataset split method

The local Task-1 vessel specialist used five balanced, non-overlapping folds
in image-ID order. Each fold used ten validation cases and forty training
cases: `g_001`–`g_010`, `g_011`–`g_020`, `g_021`–`g_030`, `g_031`–`g_040`, or
`g_041`–`g_050` as validation. The five selected checkpoints were equally
averaged at inference.

Task 2 followed the original CMRRWNet four-fold compatibility split. The
final topology ensemble used folds 0–2, whose validation partitions were
`g_001`–`g_012`, `g_013`–`g_024`, and `g_025`–`g_036`, respectively. Model
selection used held-out fold loss; no preliminary labels were used.

### 2.3 Data augmentation

The local training pipeline applied identical spatial transformations to
images, labels, and ROI masks. Rotation was uniformly sampled from −180° to
180°, isotropic zoom from 0.7 to 1.3, and shear from −25° to 25°. Horizontal
and vertical flips were applied independently with probability 0.5. Images
used cubic interpolation and discrete masks used nearest-neighbour
interpolation.

For CFP, HSV augmentation used hue shift in [−0.02, 0.02], additive
saturation/value shifts in [−0.2, 0.2], and saturation/value multipliers in
[0.8, 1.2]. Random cutout was applied with probability 0.8 using 16
rectangles of 4% image height and width, filled uniformly in [0.4, 0.6]. FFA
channels received the spatial transformations but not CFP HSV augmentation.

### 2.4 Preprocessing

All official inputs were full-resolution 1536 × 1024 images. Pixel values were
converted from uint8 to float32 in [0, 1]. Task 1 received CFP RGB only;
early- and late-phase FFA were not used for Task 1. Task 2 received CFP RGB
plus the first channel from each FFA image. Images and ROI masks were
symmetrically padded to dimensions compatible with four U-Net downsampling
levels, and predictions outside the ROI were set to zero before cropping back
to the original image size. We used no CLAHE, handcrafted colour mapping, or
manual contrast enhancement.

### 2.5 Post-processing

For Task 1, the artery and vein channels were generated by the public R2-V2
CFP-only AV expert with eight-view rotation/flip TTA; the vessel channel was
the equal average of five local RRWNet folds, calibrated to a threshold of
0.40. The output channels were fixed as R2-V2 artery, local vessel, and R2-V2
vein.

For Task 2, raw and boosted three-fold ensembles were formed. The boosted
ensemble replaced the vessel channel in each fold with `max(R,G,B)`. We used
endpoint-bridged boosted artery/vein channels with the raw-ensemble vessel
channel, then applied an additive-only deterministic vein-support mask. No
output pixel was removed by the final vein operation.

For Task 3, biomarkers were extracted from a fixed Source-E segmentation
ensemble and a SegFormer optic-disc/cup mask. We applied a global,
rank-preserving 35% empirical-quantile calibration to AVR and vein density,
constant offsets to artery and vein fractal dimensions, and recomputed CRAE
as AVR multiplied by CRVE. The same fixed rule was used for all cases.

## 6. Training Strategy

All local models used PyTorch, random seed 77, batch size 1, two data-loader
workers, automatic mixed precision, and Adam with zero weight decay. Training
and final verification were performed primarily on one NVIDIA GeForce RTX 2080
(8 GB VRAM), Intel Core i7-7700 CPU, and approximately 32 GB RAM. Some
Task-1 continuations were run on Kaggle Tesla T4 GPUs; the selected checkpoint
files were later hash-verified locally.

The Task-1 local model was RRWNet with three CFP input channels, base width
16, and five recurrent refinement iterations. It was trained using
`RRLoss(BCE3Loss)` with initial learning rate `1e-4`. The five final
checkpoints corresponded to best iterations 53160, 52760, 67560, 63800, and
62840.

The Task-2 model was CMRRWNet with five input channels, base width 16, and
one recurrent iteration. Baseline models used `RRLoss(BCE3Loss)` at learning
rate `1e-4`; the three selected models were subsequently topology fine-tuned
using `RRLoss(OfficialScoreLoss)` at learning rate `1e-5` with early-stopping
patience 20. `OfficialScoreLoss` combines differentiable A/V classification,
vessel Dice, centerline-recall topology proxy, auxiliary BCE, vessel
consistency, background suppression, and A/V mutual-exclusivity terms.

At inference, all local models were evaluated once without test-time
augmentation. The R2-V2 Task-1 specialist alone used its upstream eight-view
rotation/flip TTA. Checkpoint selection used the minimum held-out validation
loss. The submitted checkpoints contain model state dictionaries; optimizer
state is not required for inference.
